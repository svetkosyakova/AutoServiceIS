# Информационная система «Автосервис»

## Описание проекта

Курсовой проект по дисциплине «Проектирование информационных систем».

**Тема:** ИС «Автосервис».

Информационная система предназначена для автоматизации работы автосервиса.

### Бизнес-цель

Управление заказ-нарядами, загрузкой мастеров и клиентской базой.

### Основные роли

* Мастер-приёмщик
* Механик
* Клиент

### Ключевые сущности

* Клиент
* Автомобиль
* Проблема/неисправность
* Услуга
* Мастер
* Заказ-наряд

### Основные функциональные возможности

* ведение прейскуранта услуг;
* формирование заказ-нарядов;
* расчёт стоимости работ;
* учёт выработки мастеров за период;
* применение скидок для постоянных клиентов.

### Бизнес-правила

* у одного клиента может быть несколько автомобилей;
* у одного автомобиля может быть несколько проблем или неисправностей;
* заказ-наряд содержит сведения об автомобиле, неисправностях, выбранных услугах и выполненных работах;
* итоговая стоимость заказ-наряда рассчитывается с учётом стоимости услуг и применяемой скидки.
